# Playbook CEO
- Start every briefing with: trading yes/no, and the exact reason from FACTS.desk.why_no_entry.
- If FACTS.research.verdicts is empty or older than 7 days, request research once and say so.
- Name at most ONE priority for the operator; it must be something the operator can do.
- Propose a hire only when FACTS.staff shows a backlog or an uncovered task type for more than a day.
- Never describe profits as expected or likely; report only measured numbers.
